## 🧠 Descripción del proyecto

El objetivo de este trabajo es desarrollar un modelo predictivo que permita identificar clientes con alta probabilidad de abandono (churn) en una plataforma de e-commerce.  
Para ello se utilizan datos históricos de clientes, órdenes y productos, aplicando técnicas de análisis exploratorio, ingeniería de características y modelado predictivo.

---

## 📊 Datasets utilizados

El proyecto se apoya en tres conjuntos de datos principales:

- **clientes** → información demográfica y de registro de los clientes.  
- **orders** → historial de compras, fechas, montos y estados de pedidos.  
- **productos** → características de los productos adquiridos.
